# Month 08, 2026

## Arc

- **Неделя 32 — запуск конвейера.** Threads переведён на официальный API (первый боевой пост 05.08), X-аккаунт заблокирован (403 code 64), апелляция подана; обложки ушли с платной генерации на бесплатный Pollinations и закреплён вайб канала — киберкот Борис. Запущены астро-расписания 07:00/08:00, закрыт пилот prompt caching (гипотеза не подтвердилась), согласован план faceless YouTube.
- **Неделя 33 — выход на поток.** Публикации ежедневные, до 6 постов в сутки; тексты пишет пул iva-write (победитель opus46), провенанс логируется. Зафиксированы стили обложек по площадкам, правила контента и «котятки». Подключён Buffer и утренний автоотчёт по Threads; ответы на комментарии — через humanizer. Сайт toharo-lab получил функционал статей; HD-продукт (бот за 499 ₽/мес) подошёл к дедлайну 18.08; обновление Ивы снова упало.
- **Неделя 34 — видео и укрепление Ивы.** Опубликована статья dsh-vision-router; srt-whiteboard отработал в бою — первое видео-сообщение в Threads (роборука ADEPT) через дописанную видео-ветку API. В custom-слой перенесены scout/ship, adversarial review и ahoy, подключено зрение deepseek-v4-flash-vision-exp, заведён блокнот сессии; причины падения обновления найдены и устранены. Слабые показатели 20.08 и раскрытый ключ RouterAI показали: выпуск ≠ охват, а секрет в чат попадать не должен.
- **Неделя 35 — source-first разворот.** Владелец голосом решил собирать новости через сильных авторов-первоисточников: собран список YouTube-каналов P0–P2, watchlist X стал главным входом, подготовлена методика persona-скиллов (NotebookLM → Gemini → SKILL.md, пилот — Matt Wolfe, AI Explained, Dwarkesh Patel). Семиэтапный план экономии токенов закрыт как неподходящий, осталось окно 140к с замером; MarkItDown решено встраивать локальным CLI. 29.08 день прошёл полностью автоматически.
- **Хвост месяца.** 31.08 — по просьбе владельца заведён дневник идей (реестр + подробные файлы, правило сверяться в CORE), поднята идея переезда с арендованного VPS на своё железо (Pi 5 против мини-ПК N100, отложено).
