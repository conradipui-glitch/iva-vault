# 2026-08-23

## Topics

- **Самообучающаяся контент-система** — владелец одобрил («внедряем») SQLite-хранилище снимков метрик, provenance, признаков, золотых постов, гипотез; CLI iva-content-learn.py в custom-слое.
- **Context7 MCP** — по просьбе владельца подключён официальный Context7 с локальным privacy-прокси (127.0.0.1), двумя read-only инструментами, выводом до 8000 символов, изоляцией от .env/vault/SSH/GPG/user D-Bus.
- **Токен-оптимизация Iva** — этап 2 (watchdog 20/30/50) доведён до реальной отмены на disposable-сессии, но к вечеру gate оставался FAIL; в 20:30 владелец остановил разработку и заказал передачу внешнему агенту (EXTERNAL-AGENT-HANDOFF/PROMPT).
- **Сторож Iva** — после двух срабатываний на реальные длинные ходы (41→84→91 и 44) внедрён iva-watchdog.py: systemd timer 30 сек, агрегация бюджета родительского хода с субагентами, кооперативная отмена только доказанно активного.
- **Promptbook** — по команде «тяни код из репозитория и внедряй» добавлен вендор-копией в custom-слой (iva-promptbook.py + книга); adversarial review дошёл до NEEDS_WORK из-за недоказанных проверок.
- **Оркестрация субагентов** — аудит ролика свёл к выводу «Thin Root + Task Workers»: тонкий координатор + 0–4 узких worker'а, без армии агентов.
- **Публикации Threads** — обзор метрик за 22.08, выбор серии вечера (OpenBot, MCP Roadmap, локальная LLM) и полные черновики для TG/Threads.

## Highlights

- Владелец: «внедряем» по контент-системе; Ива спроектировала schema.sql, policies.json, CLI и порядок внедрения (6 шагов).
- Context7 подключён и встроен в gstack-workflow; несколько раундов adversarial review довели до ready/низкий риск. Остался только /restart владельцем.
- Watchdog этапа 2 показал жёсткую отмену на disposable-сессии и реальный детект на Telegram-ходе; формальный gate этапа не закрыт — разработка остановлена владельцем в 20:30 и передана внешнему агенту через handoff и промпт.
- Promptbook внедрён в custom-слой по правилам обновляемости; финальный ревью вернул NEEDS_WORK — нет зафиксированных прогонов core typecheck / content-learning check / selfcheck.
- Серия вечера: OpenBot (главный), MCP Roadmap, локальная LLM с интригой; Autoprompt — сначала отдельный тест, потом статья на toharo-lab; Context debt — в Telegram/сайт. Очередь не трогалась, черновики готовы.
