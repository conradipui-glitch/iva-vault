# 2026-09-05

## Topics

- **Постинг в Threads** — попытка поставить 3 поста потерпела ошибку: в `--image` передан голосовой `.ogg`; у Threads API только `.jpeg/.jpg/.png`. Задачи упали, обложки перегенерированы, №1 восстановлен.
- **Модели в веб-панели** — запрос добавить «GPT-6 Astra» и уровни мышления: модели нет в авторизованном `/models` каталоге Codex, не добавлена.
- **Стиль обложек Threads** — владелец прислал скриншот поста и одобрил ризограф-постер (крем #F5EBD7, чёрные контуры, оранжевый акцент); стиль заменил графит в `cover-styles.json` (закреплено в карточке «Стили обложек»).
- **Формат постов-мыслей** — задан строгий формат для личного AI-блога (суть в первом предложении, без эмодзи/тире/личного опыта, JSON).
- **Парк «Вокруг света»** — рассылка программы на 6–7 сентября (квартирники, альпаки).
- **Озвучка YouTube** — запрос на русский дубляж ролика (iva-yt-dub).

## Highlights

- Три Threads-задачи упали из-за передачи `.ogg` как обложки; исправлено перегенерацией, №1 опубликован, установлено правило-защита.
- GPT-6 Astra отсутствует в Codex API — добавление откачено, урок про проверку модели через live-каталог.
- Новый стиль Threads — ризограф-постер принят владельцем; закреплён в `cover-styles.json`.
- Урок поведения: не пересказывать владельца в третьем лице — говорить напрямую (замечание 22:53).
