# 2026-08-08 — Публикации, обложки Pollinations, адаптация gstack, образ Ивы

## Topics
- **Публикации в канале (Telegram @stringikotaborisa)**: утром 2 поста — «OpenAI случайно атаковала Hugging Face» (таймлайн инцидента) и «DeepMind WeatherNext — модель ураганов»; вечером 3 поста — Seedance 2.5 (бесплатные кредиты $5000/33 дня), Kimi K3 (самая крупная открытая модель, ссылка на HF), gstack Гэрри Тана (127K★, ссылка на GitHub). Лимит канала (2 поста/сутки) превышен на 1 осознанно с согласия владельца.
- **Threads**: пост-польза про Seedance 2.5 + комментарий с деталями (мультимодальные референсы, motion +30%) через --reply-to.
- **Обложки → Pollinations (решение 08.08)**: обложки постов теперь только бесплатный Pollinations API (zimage 1024×1024/1280×720, с seed — можно перегенерить точно такую же, safe=true), платную iva-image/gpt-image для обложек больше не использовать (утренние обложки стоили 4,36 и 1,09 ₽). Превью через iva-pollinations-preview.
- **gpt-image-2 → дизайн/UI-макеты**: разрешено для дизайн/UI-макетов и картинок под задачи (НЕ обложки), цену называть до запуска.
- **gstack (Garry Tan, CEO YC)**: изучен репозиторий — личный Claude Code-сетап (23 «специалиста» + 8 power-инструментов, slash-команды на Markdown, Think→Plan→Build→Review→Test→Ship→Reflect, 127K★/19.1K форков/362 коммита). Решение: адаптировать методологию, а не ставить как есть. Создан скилл `gstack-workflow` (data/custom/agent/skills/, подхватится после `npm run build` + рестарт): полный цикл, plan-review, pre-ship check, дизайн-задачи через gpt-image (идея /design-shotgun). Аналоги: grill-me≈office-hours, code-audit≈cso, postmortem≈retro, safe-release≈careful.
- **Образ Ивы**: по просьбе Антона сгенерированы 2 версии образа через gpt-image-2 (дерево-ива из световых потоков + девушка-ива, ~0.6 ₽ каждая), файлы в /root/iva/data/media/, карточка cards/notes/образ-ивы-светящаяся-цифровая-ива.md. Антон сохраняет образ в памяти.
- **Границы генерации**: откровенный NSFW Иве генерировать нельзя (в т.ч. через Pollinations — safe=true отрежет); доступны художественное ню «на грани», fashion-образы, купальники, реклама белья (несколько проб 22:52–22:56).
