# Посты готовить по доступным материалам без подтверждения

11.09.2026, 16:37 владелец: «так готовим посты какие есть каких нет не готовим запускаем что все это работало». Формулировка закрепилась в CORE: посты готовить только по уже доступным материалам, без предварительного подтверждения; выпуск (публикация) — по отдельной явной просьбе.

Причина: конвейер простаивал в ожидании согласования, хотя материала в хранилище достаточно. Подтверждение на этапе подготовки не нужно, согласование остаётся только на выпуск.

Практическое следствие: черновики делаются сразу по подборке; темы без источника не придумываются, а просто не попадают в набор. Публикация в TG-канал кота Бориса и Threads запускается отдельной командой.
