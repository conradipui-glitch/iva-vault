# Финальный формат постов Стрингов кота Бориса

## Решение · 1 августа 2026
- В иллюстрациях запрещены читаемый текст, буквы, кириллица, логотипы и водяные знаки: текущая бюджетная модель Pollinations ненадёжно рисует русский текст.
- В конечных постах канала не указывать ссылки и отдельный блок «Источники».
- Прямые ссылки и дата источника обязательны на этапе проверки фактов и в редакционных черновиках, но не переносятся в финальную публикацию.
- Для подготовки текста использовать специализированный редакционный подход/скилл, а не механическое сокращение черновика.

## Статус автоматизации
Правило о запрете текста уже присутствует в visual prompt выключенной тестовой n8n workflow `Iva • Boris Editorial Queue — manual test`. Полноценное подключение редакционного skill к n8n требует отдельной реализации: n8n не может вызывать внутренний агентский skill сам по себе без явного интерфейса/вебхука.

## Уточнение · 1 августа 2026
- На иллюстрациях не должно быть читаемого текста, букв или кириллицы: бюджетная модель Pollinations ненадёжно их рисует.
- Водяные знаки запрещены.
- Логотип компании допустим, когда он прямо релевантен сюжету новости. Не добавлять его как декоративный элемент и не использовать вместо визуальной идеи.

## Статус автоматизации
В visual prompt выключенной тестовой n8n workflow сейчас всё ещё есть запрет логотипов. Его надо заменить на правило: «без текста/букв/водяных знаков; логотип только релевантной компании допустим при необходимости сюжета».
