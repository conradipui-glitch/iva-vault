# Автоматизация X: 3 поста в день + еженедельный анализ

## Решение · 1 августа 2026 (полный автомат)
Владелец выбрал: **полный автомат**, публикация без ручного согласования. Аудитория — **русскоязычная** (РФ + диаспора), не Москва/Сибирь специально, широкая. Telegram пока на паузе (нет аудитории, не жечь токены).

## Автоматизация X
- **3 поста/день**: 08:00, 13:00, 19:00 Asia/Omsk (= 04:00, 09:00, 15:00 Europe/Amsterdam, системное время сервера).
- Скрипт: `/root/iva/scripts/x-auto-post.mjs` — eve-сессия подбирает свежую AI-новость с виральным потенциалом, пишет пост в X-формате (хук → суть → вопрос, ≤260 знаков, без ссылок), промпт картинки без текста → n8n/Pollinations вебхук → публикация через GraphQL.
- Крон: в `/etc/crontab`, логи `/var/log/x-auto-post.log`.
- После каждого поста — короткое подтверждение владельцу в Telegram.

## Еженедельный анализ
- Скрипт: `/root/iva/scripts/x-weekly-report.mjs` — метрики (просмотры, лайки, репосты, ответы, закладки, вовлечённость) за неделю, лучший пост, рекомендация.
- Cron: воскресенье 14:00 Amsterdam = 18:00 Omsk. Отчёт в Telegram.

## Технические проблемы и решения
- CLI `twitter post` сломан (падает в обёртке) — рабочий путь: прямой GraphQL через `twitter_cli.TwitterClient` (curl_cffi chrome133a).
- **Soft-block X**: после серии тестов CreateTweet возвращает 200 + пустой `tweet_results` (X молча отбрасывает запись). Чтение работает. Скрипт НЕ спамит повторами — 1 попытка на слот, пропуск при пустом ответе (exit 2), лог.
- Важно: НЕ долбить запросы при soft-block — риск бана аккаунта. Ждать снятия (15–60 мин).
