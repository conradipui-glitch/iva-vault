# Постинг в X: рабочий способ и виральный формат

## Решение · 1 августа 2026
- Рабочий способ постинга в X найден: CLI `twitter post` падает (баг обёртки), рабочий путь — прямой GraphQL-запрос CreateTweet через `twitter_cli.client.TwitterClient` (curl_cffi, chrome133a фингерпринт). Картинки: `upload_media` → `media_id` → `media_entities` в CreateTweet.
- Тестовый пост опубликован: https://x.com/TrampampamAGI/status/2083579198443012112 (с фото, media подтверждено через `fetch_user_tweets`).
- Владелец: «если есть рабочий способ — делай как лучше». Требование: посты должны быть виральными, чтобы алгоритмы Twitter их подхватывали.

## Правило «виральность для X»
Формат постов для X (отличается от Telegram):
- Первая строка — сильный цепляющий хук (вопрос/факт/конфликт), не «Котятки, на проводе Борис» в начале.
- Короткие абзацы, 1 идея, провокационный вопрос в конце для вовлечения (комментарии).
- Хэштеги — 1–3 релевантных, в конце (или вообще без них, если не помогают).
- Обложка/картинка обязательна (X даёт буст постам с медиа).
- Время публикации — пик активности аудитории (обычно будни 12:00–15:00 и 18:00–20:00 по времени аудитории).
- Без ссылок в тексте (ссылка режет охват); при необходимости — короткая ссылка в первом ответе/комментарии.
- Взаимодействие после публикации: отвечать на комментарии первые часы (алгоритм любит раннюю вовлечённость).

## Статус
Правило зафиксировано; следующий пост для X готовится по этому формату. CLI-обёртку не чинили (рабочий обход есть).
