# внедрение-самообучающейся-контент-системы-sqlite

23.08.2026 владелец сказал «внедряем» по предложенной архитектуре самообучающейся контент-системы. Идея ранее была оформлена (самообучающаяся контент-система) и теперь переходит в реализацию.

Архитектура (всё в custom-слое, апстрим не трогаем):
- data/custom/content-learning/: schema.sql, policies.json, content.db, tests/.
- data/custom/scripts/iva-content-learn.py — CLI (db init/check, sync stats, sync provenance, collect, features build/show, gold, hypotheses, curator recommendations).
- Источники импорта — существующие data/threads-stats.json (65 постов с полными метриками) и data/posts.jsonl (36 provenance-записей, из них 20 для Threads). Остаются резервной совместимостью.

Проверенное состояние на 23.08: 65 постов с полным набором метрик; 36 provenance-записей (20 Threads); у 19 Threads-записей есть URL, но только 15 точно сопоставляются с threads-stats.json; одна старая запись без URL остаётся несвязанной; для куратора «максим-ильяхов» только 7 записей — выводы о его эффективности запрещены правилом n<10.

Ключевые правила: снимки метрик неизменяемые (повторный импорт идемпотентен); повторные снимки одного поста не считаются независимыми наблюдениями; features привязаны к feature_version и SHA текста; в det-v1 только воспроизводимые признаки (длина, абзацы, URL, вопросы, эмодзи, медиа, местный час/день, фиксированные regex-теги) — LLM-классификация не называется детерминированной. Для сравнительного вывода нужно минимум 10 постов в каждом плече, при n<10 finding можно хранить как insufficient, но не показывать как паттерн. Золотые кандидаты отбираются автоматически, но в библиотеку входят только approved; публикация и одобрение остаются за владельцем. Рекомендация куратора хранит объяснимую основу (basis: policy/hypothesis/gold-similarity/mixed).

Порядок внедрения: 1) SQLite и история snapshots; 2) автоматические признаки + provenance новых постов; 3) библиотека «золотых»; 4) отчёт фактов и гипотез без LLM; 5) раз в 2–4 недели глубокий кураторский разбор; 6) рекомендатель нарратива/визуала/кураторов. Первый рабочий результат — понятная карточка каждого нового материала, не «автор постов».

Reach-порог золота: reach_floor = max(250, P75 просмотров зрелых постов за 90 дней). По текущим данным абсолютный порог 250 проходят многие, динамический P75 ориентировочно ~500–550.
