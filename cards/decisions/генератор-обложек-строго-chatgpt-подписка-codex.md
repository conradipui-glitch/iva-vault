# Генератор обложек — строго ChatGPT-подписка (codex)

Решение владельца 20.09.2026: изображения для канала «Стринги кота Бориса» и для Threads генерируются строго через ChatGPT-подписку (обёртка codex) — путь внутри уже оплаченной подписки. Причины: Pollinations игнорирует русские промпты (вместо сцены — дефолтный портрет девушки) и лепит watermark на больших размерах (1600×900; на квадратных 1024 в тестах чисто); Antigravity с 19.09 отвалился по региону; RouterAI gpt-image-2 — платный, баланс минусовой. Muse Image недоступен: ни ключа, ни публичного API у Meta Muse нет. Тесты 20.09: codex-генерация 1536×1024; Threads-стиль (ризограф, крем #F5EBD7, оранжевый акцент) — стресс-тест 5/5, стабильно 1:1 без watermark; в промпты зашиты запреты людей, текста, логотипов и водяных знаков.
