# Стили обложек по площадкам: разделение TG/сайт/Threads

С 16.08.2026 перед генерацией обложки нужно сверять площадку и её отдельный стиль.

- Telegram-канал «Стринги кота Бориса»: дерзкий киберкот Борис в тёмной неоновой серверной, teal/amber/magenta, без текста, букв и логотипов; кот желателен в кадре.
- Сайт toharo-lab: кремовый фон, лаймовый акцент, плоская векторная графика, без текста.
- Threads @toharo_pro: тёмно-графитовый фон, один яркий лаймовый или бирюзовый акцент, минимализм, без кота и другого маскота.

16.08.2026 обложки для TG сначала ошибочно сделали в стиле сайта; после замечания владельца их пересоздали в вайбе Бориса. Предложенный стиль Threads владелец одобрил, и три утренних поста вышли с ним.

## Log

- 2026-08-16:
  16.08.2026 владелец указал на путаницу: обложки для постов делаются в стиле площадки, а не «одном на всё». Правила:
  
  - **Telegram-канал «Стринги кота Бориса»** (@stringikotaborisa): вайб канала — «дерзкий киберкот-хакер Борис в тёмной неоновой серверной», teal/amber/magenta, без текста/букв/логотипов (см. [[cards/decisions/обложки-вайб-канала-кот-борис]]). Кот желателен в кадре.
  - **Сайт toharo-lab**: кремовый фон + лаймовый акцент, плоская векторная графика, без текста (см. [[cards/notes/toharo-lab-обложки-gpt-image-2-через-routerai]]).
  - **Threads** (личный аккаунт про ИИ, без котиков): утверждён 16.08.2026 — тёмно-графитовый фон + один яркий акцент (лайм/бирюза), минимализм, геометрические формы, без маскота; кот — только в TG-канале Бориса.
  
  Ошибка 16.08: для черновиков TG-канала сгенерированы обложки в стиле сайта (крем/лайм flat) — перегенерировано в вайбе Бориса. Перед любой генерацией обложки проверять карточку стиля площадки.
- 2026-08-17:
  17.08.2026: нарушение — анонс статьи и новость archify ушли в TG-канал Бориса с сайт-обложкой (крем/лайм). Владелец отчитал: «В телеграм генерация изображений должна быть в определённом стиле, то что вышло с постом этот стиль только для сайта».
  
  Исправление: старые посты удалены (TG deleteMessage, Threads Graph API DELETE с access_token в query), пересозданы с правильными обложками. Владелец: «в тредс пусть как есть уже останется».
  
  Правило-напоминание при генерации обложек:
  - TG-канал Бориса (@stringikotaborisa) → ВСЕГДА вайб «дерзкий киберкот-хакер Борис»: тёмная неоновая серверная, светящиеся глаза, лапа на терминале, teal/amber/magenta, кот в кадре, без текста/логотипов.
  - Сайт toharo-lab → кремовый flat с лаймовым акцентом.
  - Threads → тёмно-графитовый минимализм, один яркий акцент, без маскота/кота.
  Никогда не использовать стиль сайта для TG и наоборот. Сначала превью владельцу на согласование.
