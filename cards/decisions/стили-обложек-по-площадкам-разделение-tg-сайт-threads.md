# Стили обложек по площадкам: разделение TG/сайт/Threads

16.08.2026 владелец указал на путаницу: обложки для постов делаются в стиле площадки, а не «одном на всё». Правила:

- **Telegram-канал «Стринги кота Бориса»** (@stringikotaborisa): вайб канала — «дерзкий киберкот-хакер Борис в тёмной неоновой серверной», teal/amber/magenta, без текста/букв/логотипов (см. [[cards/decisions/обложки-вайб-канала-кот-борис]]). Кот желателен в кадре.
- **Сайт toharo-lab**: кремовый фон + лаймовый акцент, плоская векторная графика, без текста (см. [[cards/notes/toharo-lab-обложки-gpt-image-2-через-routerai]]).
- **Threads**: стиль пока НЕ определён — владелец просит предложить.

Ошибка 16.08: для черновиков TG-канала сгенерированы обложки в стиле сайта (крем/lайм flat) — перегенерировано в вайбе Бориса. Перед любой генерацией обложки проверять карточку стиля площадки.
