# Стили обложек по площадкам: разделение TG/сайт/Threads

С 16.08.2026 перед генерацией обложки нужно сверять площадку и её отдельный стиль.

- Telegram-канал «Стринги кота Бориса»: дерзкий киберкот Борис в тёмной неоновой серверной, teal/amber/magenta, без текста, букв и логотипов; кот желателен в кадре.
- Сайт toharo-lab: кремовый фон, лаймовый акцент, плоская векторная графика, без текста.
- Threads @toharo_pro: тёмно-графитовый фон, один яркий лаймовый или бирюзовый акцент, минимализм, без кота и другого маскота.

16.08.2026 обложки для TG сначала ошибочно сделали в стиле сайта; после замечания владельца их пересоздали в вайбе Бориса. Предложенный стиль Threads владелец одобрил, и три утренних поста вышли с ним.

## Как это работает с 18.08.2026

Стиль больше не надо помнить и не надо искать в памяти — его подставляет код.
Единственный источник: `data/custom/cover-styles.json`. Оба пути генерации
читают этот файл:

- по умолчанию, бесплатно: `iva-pollinations-preview '<seed>' '<сюжет>' '<текст>' tg|site|threads`
- по прямой просьбе владельца назвать модель: `iva-image gen '<сюжет>' --for tg|site|threads`

Смена генератора НЕ меняет правил площадки. Описывать стиль своими словами
нельзя — разойдётся с файлом. Менять вайб площадки — править только этот файл.
