# buffer-аналитика-и-лимиты-threads-250

Владелец подключил Buffer API для аналитики; Ива читает статистику через `iva-buffer stats`. 14.08: видны все 10 постов за 14 дней (просмотры, отклики, вовлечение, крючки). Суммарное вовлечение 0,70%, медиана Threads — 6,25% — заметно ниже среднего. Лучший крючок — «Gemini 4 слили — уже скоро» (1694 просмотра, 11 откликов), слабее всех — про сайт-пародии. У свежих постов (сегодняшние) аналитика ещё не посчитана — 0 просмотров нормально, подтянется через несколько часов. Постов с данными меньше десятка — выводы о закономерностях рано; предложен регулярный еженедельный разбор (что зашло/не зашло, по крючкам).

Лимит 250 — это квота Buffer, не Threads: в приложении Buffer «осталось 245 из 250» — месячный лимит публикаций через сам Buffer (Threads 250/мес, Instagram 50/мес). Посты, опубликованные напрямую через Threads API своим скриптом (минуя Buffer), в этот счётчик НЕ попадают — лимиты Threads для прямого API другие и гораздо выше. 245 из 250 — просто запас внутри Buffer, он почти не используется.
