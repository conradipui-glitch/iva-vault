# X-источники: веб, AI-инструменты, SaaS

Использовать только когда владелец просит подборку по этим источникам или явно просит веб-разработку/AI-инструменты/SaaS.

- `@shadcn` — UI-компоненты, registry, React-интерфейсы.
- `@swyx` — AI-инженерия, agent harness, LLM-инструменты.
- `@rauchg` — Гильермо Раух, Vercel, веб-платформа и AI-инфраструктура.

Правила:

1. Хендл первичен. Не подменяй автора похожим именем: `@rauchg` — не Rahul Vohra.
2. Для каждого использованного факта укажи прямую ссылку на X и дату/время поста, если источник её отдал.
3. Если посты есть, но не по теме, так и скажи; не выдавай наличие активности за релевантность.
4. При ручном запросе верни подборку или черновики в личный чат владельца. В канал не публикуй и изображения не генерируй, пока это прямо не запрошено.
5. Для значимого факта по возможности добавляй официальный первоисточник: документацию, релиз, GitHub или блог компании.
