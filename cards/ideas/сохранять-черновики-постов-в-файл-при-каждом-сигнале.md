# Сохранять черновики постов в файл при каждом сигнале

23.09.2026 владелец одобрил утренние черновики («по черновикам — одобряю — срочно в прод»), но тексты сигналов нигде не сохранялись — восстановить их было нельзя, в Threads опубликованы свежие посты по тем же топ-трендам. Ива предложила сохранять черновики в файл при каждом сигнале, чтобы механика «одобряю — в прод» работала с первого раза; решения владельца пока нет.
