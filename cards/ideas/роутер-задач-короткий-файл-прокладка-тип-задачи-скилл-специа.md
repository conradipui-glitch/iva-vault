# Роутер задач: короткий файл-прокладка тип задачи → скилл/специалист

Гипотеза владельца (13.08.2026, msg 14:45): есть файл с базовыми инструкциями, который «толстеет»; предложение — файл-прокладка (1–2KB), который не ломается при обновлении репозитория и по типу задачи (написание поста / серверная задача / разбор) коротко указывает, к какому основному файлу/скиллу/специалисту обращаться, с минимальной тратой контекста.

Ответ Ивы: CORE.md — уже «короткая инструкция» (грузится всегда); большие `agent/instructions/*` и `skills/` подгружаются по необходимости. Улучшение по идее: сделать CORE ещё тоньше (кто пользователь + ≤3 цели + указатели), детали в карточки; добавить роутер-скилл (1–2KB) — при старте задачи смотрит тип и подсказывает скилл/специалиста, вместо хранения всех правил в голове. Параллельно начато логирование специалистов в posts.jsonl (сейчас none, если без).
