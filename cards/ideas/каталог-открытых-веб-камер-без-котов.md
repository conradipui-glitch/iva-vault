# каталог-открытых-веб-камер-без-котов

15.08.2026 (голос, msg 1835): владелец упростил идею — пока без котов, просто «собрать максимум открытых камер» и отобразить в интерфейсе (сайт с кучей камер). Готов рассматривать любой регион/диапазон.

Проверено поиском (15.08):
- Windy Webcams API — крупнейший каталог веб-камер мира, бесплатный тариф, ключ через windy.com; эндпоинты: список по стране/региону/bbox/nearby, превью, таймлапсы. Картинки с токеном, на free истекает через 10 минут — URL надо обновлять при загрузке страницы.
- Омск: geocam.ru (17 камер), admomsk.ru (официальный портал, архив), smotriomsk.ru, youwebcams.org, webcam-oko.ru.
- EarthCam — большой каталог, публичного API по сути нет.

Границы: только официально публичные источники/API, где владелец сам выложил поток. Без сканеров (Shodan/Insecam), обхода авторизации и поиска скрытых камер.

Предложенный MVP: парсер на VPS (Windy API + локальные каталоги) → база (id, координаты, регион, превью, ссылка) → фронт на GitHub Pages (Leaflet-карта с камерами, клик = превью) → закрытая панель на VPS (FastAPI: источники, статусы, ручное добавление). Открытые вопросы: регион (Омск/РФ/мир), готовность завести бесплатный ключ Windy, публичность сайта.
