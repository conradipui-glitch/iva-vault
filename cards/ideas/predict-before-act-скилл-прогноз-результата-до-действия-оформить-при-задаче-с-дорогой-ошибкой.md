# predict-before-act: скилл «прогноз результата до действия» — оформить при задаче с дорогой ошибкой

21.08.2026 разобран arc-skill (arc-skill.vercel.app, Poobesh Gowtham): скилл для Claude Code прошёл все 25 публичных игр ARC-AGI-3 (183/183, 100.00 RHAE) за 7645 действий, но это 129 строк инструкций + 4343-строчный CLI-харнесс (поиск пути, A*) — классический benchmaxxing под один бенчмарк; для наших задач пользы ноль, чужой 4К-строчный код с ARC_API_KEY без аудита не ставим. Решили arc-skill целиком не устанавливать. Ценное из него — одно правило: «сформулируй ожидаемый результат до действия» (каждый шаг — эксперимент). Оформить как наш скилл predict-before-act (триггер: сложная многошаговая задача, где дорого ошибаться) решено позже, когда появится такая задача: сейчас идея частично покрыта (todo, planner, «проверяемость важнее уверенности», превью перед обложками), мёртвый скилл на полке не нужен.
