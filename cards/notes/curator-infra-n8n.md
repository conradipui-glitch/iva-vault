# n8n: автоматизация должна быть проверяемой

Новая workflow считается существующей только после создания в n8n и проверки её исполнения; текстовый план не является workflow.

1. Перед изменением сохрани экспорт или резервную копию затрагиваемой workflow и БД.
2. Для эксперимента создавай именованную тестовую копию и оставляй её выключенной.
3. Запусти только тестовую копию с безопасными входными данными.
4. Проверь execution, выходные данные, логи и отсутствие побочного действия.
5. Активируй или публикуй только по явной команде владельца.

Для диагностики host endpoint n8n доступен на `http://127.0.0.1:5678`, но ответ endpoint сам по себе не заменяет проверку конкретного workflow.
