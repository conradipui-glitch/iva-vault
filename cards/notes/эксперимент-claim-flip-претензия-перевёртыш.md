# Эксперимент claim-flip (претензия-перевёртыш)

Эксперимент от 08.09.2026: подача новостей методом «Претензия-перевёртыш» (источник — рил Макса Брагина https://www.instagram.com/reel/DaJcB3AMXB4/, 28.06.2026).

Метод: первая строка = претензия/плохая новость (пугает в превью) → в середине разворот «на самом деле…» → облегчение → применимый вывод → ссылка в конце. Эмоциональная дуга: тревога → разрыв шаблона → облегчение → готов слушать.

Оформлено как скилл data/custom/agent/skills/claim-flip/SKILL.md (5 шагов, запреты, проверка).

Первое применение: 3 новости из подборки b-20260908-1837 (Mistral €3B / RSA-ключи CA из 90-х / агенты Данияра Хафнера) — черновики для TG-канала Бориса и Threads со сгенерированными обложками в стиле площадок.

Как мерить успех: сравнить вовлечённость (buffer / iva-posts-report) с постами, написанными обычным крючком; смотреть дочитывания/отклики в первые 60 минут. Если claim-flip-посты стабильно выше медианы канала (0.84%) — оставить как рабочий приём; если нет — вернуть обычный крючок.
