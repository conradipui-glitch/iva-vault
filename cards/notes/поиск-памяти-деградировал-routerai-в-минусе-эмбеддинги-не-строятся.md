# Поиск памяти деградировал: RouterAI в минусе, эмбеддинги не строятся

23.09.2026 утром владелец заметил просадку здоровья vault (93.9 → 93.5) и ухудшение поиска по памяти. Причины две. Первая — битые ссылки после переименований карточек: починены штатным graph.py fix + руками, здоровье вернулось к 100.0, битых managed-ссылок 0, закоммичено в vault-repo. Вторая — ночной iva-brain упал на пересборке векторного индекса: RouterAI на балансе −0,45 ₽ («Недостаточно средств»); эмбеддинги делаются через RouterAI, без них поиск работает на голом BM25 и находит меньше и тупее. Варианты, предложенные владельцу: (1) пополнить RouterAI на пару сотен рублей — индекс пересоберётся ночью сам (~1 ₽ за миллион токенов); (2) бесплатно и локально — ollama + nomic-embed-text (~270 МБ), переключить эмбеддинги на него. Выбор на утро 24.09 не сделан.
