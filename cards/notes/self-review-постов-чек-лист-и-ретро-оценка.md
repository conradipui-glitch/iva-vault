# self-review-постов-чек-лист-и-ретро-оценка

## Self-review постов (10.08.2026)

Предложение по self-review из идей langchain-sma (reflection-агент + evals) — применено к нашему конвейеру:

1. **Чек-лист перед публикацией** (вместо полного reflection-агента): перед постановкой в очередь черновик проходит 5 проверок — хук за 1-ю строку, конкретика (числа/названия), вопрос в конце, отсутствие ссылок в теле (Threads), длина. Оценка 0/1 по каждой; при <3/5 — переписать, не публиковать.
2. **Ретро-оценка черновиков** (аналог src/evals/): раз в день смотреть на опубликованное — просмотры/реакции, какие хуки сработали. Накопить статистику → уточнять формулу.
3. **SENT-дедуп** уже есть (news-mark.mjs помечает status: sent) — можно добавить «не повторяем тему за 7 дней» в auto-state.

### Реализация
- 11.08: скилл `post-review` (data/custom/agent/skills/post-review/SKILL.md): автопроверка тональность/клише/«написано ИИ» + ретро-оценка. Перед любой публикацией — прогнать черновик (см. CORE, 11.08).
