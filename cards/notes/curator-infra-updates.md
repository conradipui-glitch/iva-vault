# Контролируемые обновления

Обновление — это изменение системы, а не механическое получение последнего образа.

1. Зафиксируй текущую версию и проверь release notes целевой версии.
2. Отдели патч, минорное и мажорное обновление; для мажорного отдельно проверь breaking changes.
3. Сделай бэкап конфигурации и данных, подготовь предыдущую версию для отката.
4. Обнови один компонент, проверь статус, логи и ключевой пользовательский сценарий.
5. Зафиксируй результат и новую версию в документации.

Watchtower/Renovate могут помогать замечать обновления, но не должны бездумно применять изменения к критичным сервисам.
