# Шлюз проверки дублей iva-dup-check

- 2026-09-20: По поручению владельца («прежде чем публиковать — проверяй дубли») внедрён шлюз `iva-dup-check` (`/root/iva/data/custom/scripts/iva-dup-check.py`, симлинк `/usr/local/bin/iva-dup-check`). Проверяет URL и текст по трём источникам опубликованного: `data/news/store.json` (status=sent), `data/posts.jsonl` (провенанс), `data/threads-stats.json` (все посты Threads).
- Ловит: точные/нормализованные URL (+ utm), пересечение ≥4 значимых слов слага на одном домене (RSS-слаги гуляют), дословные тексты, межъязыковые дубли (русский черновик vs английский sent-титул) через общие сущности (gpt-6, astra, adfgvx…) + русские флаг-слова.
- Встроен в `iva-news-auto` (вызов перед генерацией текстов, помечен «ЛОКАЛЬНАЯ ПРАВКА (Iva)», запись в tree-allowlist).
- Вывод расследования повторов 20.09: в записях дублей НЕТ; источник риска — параллельные конвейеры (trends-monitor шлёт черновики «на одобрение», не зная о sent-статусах news-store; threads-machine AUTO включён, но пуст — 0 публикаций).
- При ручной публикации тоже прогонять через шлюз: `iva-dup-check --url <url>` и/или stdin с текстом; exit 1 = дубль.
