# paragon-JEV: недоделанный репозиторий, для нас пользы нет

23.09.2026 владелец прислал репозиторий paragonvideomaking/paragon-JEV как «полезный скилл». Проверен вживую: скачан, код просмотрен, сервер запущен, запросы прогнаны. Это локальное демо «ТЗ перед стартом»: вставляешь ТЗ, получаешь оценку по 5 критериям (результат, скоуп, ограничения, срок, приёмка) плюс уточняющие вопросы; оценку делает внешний API TypeSafe (model jev-latest), нужен их API-ключ. Код аккуратный: чистая стандартная библиотека, один внешний вызов, ключ держится в памяти, CSRF-защита и привязка к 127.0.0.1 реально работают (проверено живьём). Но как «полезный скилл» не работает: в репо нет static/index.html — браузерный интерфейс не откроется; заявленных тестов tests/test_rules.py тоже нет (404); без ключа TypeSafe мёртв (непубличный API, ключа у нас нет); по сути учебный проект — TASK.md внутри задание для агента (под Claude Code), репо создан 22.09, 0 звёзд, автор без истории. Вердикт: для нас пользы нет — то же самое делает iva-write/planner без стороннего API. Предложен свой вариант: скилл чек-листа ТЗ (5 критериев + уточняющие вопросы) без TypeSafe и чужого кода — владелец не ответил.
