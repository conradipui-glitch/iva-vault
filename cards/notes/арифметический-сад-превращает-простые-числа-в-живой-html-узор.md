# Арифметический сад превращает простые числа в живой HTML-узор

24.08.2026 создан автономный интерактивный HTML-арт «Арифметический сад». Числа раскладываются в спираль по золотому углу, простые числа вспыхивают цветами; доступны пауза, новый сад, тихий синтезированный звук и посев света кликом. Файл находится в data/custom/lab/arithmetic-garden.html, рядом сохранено превью. После исправления одного цикла анимации, поведения на паузе и перерисовки при изменении размера проверка не нашла блокирующих проблем. Владелец оценил идею как отличную.
