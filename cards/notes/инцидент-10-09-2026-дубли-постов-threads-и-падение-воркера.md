# Инцидент 10.09.2026: дубли постов Threads и падение воркера

09.09 при добавлении ретрая публикации в scripts/iva-threads-api-post.py в конец файла случайно записался **двойной** if __name__ == "__main__": main() — main() выполнялся дважды, каждый пост выходил в Threads дублем (2 разных POST_ID). При той же правке data/custom/scripts/threads-post-with-source.sh пересоздался без бита исполнения (600 вместо 700) → воркер очереди падал с PermissionError, задачи висели в running, посты утренней подборки не вышли.

Починено 10.09: chmod +x, убран дубль main() (py_compile OK, dry-run показал один контейнер), упавшие задачи возвращены в pending. Дубли удалены из ленты (DELETE API — 6 штук: 18144894553523813, 18100591079012273, 18114309296514797, 18084755486315201, 18443747737135581, 18102033029191864). Недостающие комментарии-источники добавлены вручную (6 штук).

Итог: все 4 поста перевёртыша дня вышли в ТГ и Threads с источниками. Урок: после правки скрипта с ретраями проверять хвост файла (дубль main) и бит исполнения; синхронизировать /usr/local/bin и scripts/.
