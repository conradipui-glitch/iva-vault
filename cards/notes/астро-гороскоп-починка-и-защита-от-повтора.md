# Астро-гороскоп: починка и защита от повтора

## Проблема
07.08.2026 рефакторинг бота на TypeScript (коммиты e6e2591, d56f09d) удалил `scripts/lib/*.mjs` — остались только `.ts`. Cron-скрипты (`daily-astro.mjs`, `money-windows.mjs`, `trends-monitor.mjs`, `scripts/reminders/prompt-cache-pilot-reminder.mjs`) продолжали импортировать `./lib/telegram-send.mjs` и `./lib/env-file.mjs` → «Cannot find module». Гороскоп не приходил 08.08, 09.08, 10.08 в 07:00 (journalctl: FAILURE).

## Решение (10.08.2026)
1. **Самодостаточный модуль** `scripts/lib/telegram-send-lite.mjs` — копия функций отправки/форматирования из `telegram-send.ts`, НОЛЬ импортов (только node:fs). Не зависит от TS-слоя, не сломается при обновлении.
2. **4 скрипта переведены** на него (sed): `daily-astro.mjs`, `money-windows.mjs`, `trends-monitor.mjs`, `reminders/prompt-cache-pilot-reminder.mjs`.
3. **Сторож `scripts/guard/astro-guard.mjs`** — каждое утро в 07:05 (systemd timer `iva-astro-guard.timer`, Persistent=true) проверяет маркер `data/guard/astro-last-sent.txt` + journalctl, при сбое шлёт владельцу 🚨 алерт.
4. **Коммит `8f5c8a3`** — фикс закреплён в git, `iva update`/`git pull` не откатит.
5. `iva-astro.service` реально отработал (Finished), гороскоп отправлен, маркер записан.

## Важно знать
- Маркер пишет сам `daily-astro.mjs` при успешной отправке.
- Таймер 07:05, в первый день догнал в 11:05 (Persistent).
- `money-windows` молчит до 31.08 — это норма (нет окон).

  17.08.2026: владелец попросил «очеловечить» сырой прогноз (сесквиквадрат, дом 8 — непонятно). Собрана цепочка интерпретации:
  
  - `data/custom/scripts/astro-interpret.py` (замена нерабочего .mjs): запускает движок (transit + lunar), фильтрует ключевые блоки, шлёт в agy (gemini-3.7-flash, --effort medium, --output-format json), парсит JSON, чистит маркдаун, отправляет в TG (332664273) с префиксом «☀️ Прогноз на день». При сбое agy/отправки шлёт владельцу ⚠️-алерт. `--dry` — вывод в stdout.
  - Промпт: `data/custom/astro-interpreter-prompt.txt` (4–8 строк, без терминов и канцелярита, тёплый тон, 1–2 совета, ≤2 эмодзи, только текст прогноза).
  - Таймер: `iva-astro-interpret.timer` — OnCalendar=*-*-* 07:10:00 Asia/Omsk, Persistent=true, After iva-astro.service (сырой в 07:00 остаётся, человеческий приходит в 07:10 отдельным сообщением).
  - Урок: agy виснет (ETIMEDOUT) из node spawnSync/execFileSync даже с </dev/null и timeout 900 — но отлично работает из python subprocess.run (как в iva-write.py). Для вызова agy использовать Python-обёртки.
  - `lunar` в движке вызывается БЕЗ аргументов (иначе usage error).
