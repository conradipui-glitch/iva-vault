# MarkItDown безопаснее встраивать в Иву как локальный CLI а не MCP

24.08.2026 изучен гайд по MarkItDown MCP и сверена официальная документация Microsoft. MarkItDown преобразует PDF, Word, Excel, PowerPoint и другие форматы в Markdown, но обещание экономии токенов до 70% не гарантировано; часть форматов требует дополнительных модулей, сканированным PDF нужен отдельный OCR, а большие документы могут превысить лимит клиента. MCP принимает локальные и сетевые URI, работает с правами пользователя и не имеет встроенной авторизации, поэтому для Ивы прямое подключение не рекомендовано. Если улучшать обработку документов, безопаснее использовать закреплённую локальную библиотеку или CLI только для проверенных файлов, ограничивать размер результата, делить большие документы и сохранять текущие конвертеры как резерв.
