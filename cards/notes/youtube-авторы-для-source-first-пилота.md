# YouTube-авторы для source-first пилота

- Подборка собрана 25.08.2026 по просьбе владельца после решения о source-first; существование каналов проверено веб-поиском. Приоритеты: P0 — пилот, P1 — второй контур, P2 — точечный мониторинг.
- P0 (стартовый набор, 9 каналов): The AI Daily Brief / Nathaniel Whittemore (@AIDailyBrief) — ежедневный радар; Wes Roth (@WesRoth) — ранний сигнал без автодовера; Matt Wolfe (@mreflow) — продукты и инструменты; Matthew Berman (@matthew_berman) — быстрые тесты моделей; Last Week in AI (@lastweekinai) — полнота недели; Yannic Kilcher (@YannicKilcher) — разбор papers; Machine Learning Street Talk (@MachineLearningStreetTalk) — технический контраргумент; Dwarkesh Patel (@DwarkeshPatel) — прямые заявления лидеров отрасли; Latent Space (@LatentSpacePod) — инженерия и инфраструктура.
- P1: AI Explained (@aiexplained-official) — спокойная аналитика против хайпа; No Priors (@NoPriorsPodcast) — стартапы и экономика (венчурный уклон); Cognitive Revolution (@CognitiveRevolutionAI); Sam Witteveen (@samwitteveenai); Fireship (@Fireship) — сверхбыстрый радар заголовков; Paris Marx (@techwontsaveus) — социально-критическая оптика; Ed Zitron (@BetterOfflinePod) — скепсис по экономике AI.
- P2: Lex Fridman (@lexfridman) — только интервью с AI-гостями; Andrej Karpathy (@AndrejKarpathy) — event-driven первоисточник, не новостной канал.
- Правило source-first: видео — триггер, а не конечный источник: ролик → ссылка из описания → официальный анонс / paper / GitHub / model card → независимая проверка. Для Wes Roth, Matt Wolfe, Fireship и Berman не выпускать новость только по пересказу; интервью — первичный источник лишь для прямых слов гостя, не для истинности его прогнозов.
