# Озвучка YouTube: конвейер iva-yt

## Что умеет конвейер (описано владельцу 3 августа 2026)

4 уровня обработки англоязычного YouTube-ролика:
1. **Транскрипт** — `iva-yt-transcript <url> en`: 0 руб., если есть субтитры (у EN-роликов почти всегда); без субтитров — Deepgram ~1–2 руб. за 20 мин.
2. **Пересказ/конспект/тезисы/ответы** — только токены на обработку, ~1–3 руб.
3. **Пост для Telegram-канала** — транскрипт → news-editor + обложка: несколько рублей, точная смета перед запуском.
4. **Озвучка на русском (дубляж)** — реальные деньги: `iva-yt-cost <url> --lang ru` (смета по метаданным, 0 руб., ничего не качает) → `iva-yt-dub <url> [--video] [--max-min 60]`. ~30 руб. за 19-минутный ролик, ≈1,5–2 руб./мин; предохранитель 30 мин по умолчанию (длиннее — явный `--max-min`), лимит файла для Telegram 50 МБ (больше — отдать путь на сервере). mp3 без `--video`, mkv с ним (оригинал 1-й дорожкой, перевод 2-й). Реплики подгоняются под тайминг (ускорение до 1.6×).

## Правила и ограничения
- **Дороже ~30 руб. — только после явного «ок» владельца.** Смета всегда до запуска.
- Обычный конвейер: **один синтетический голос на всех говорящих** (это озвучка, не ролевая разбивка).
- **Разные голоса** — отдельный кастомный конвейер: `iva-src-check <url>` (проверка доступности, секунды, бесплатно; Google Drive поддерживается) → `iva-cast analyze <url> --mode multi` (диаризация: 2 собеседника, пол по тону, подбор из 37 голосов; смена через `iva-cast suggest/set`) → `iva-queue add -- iva-yt-dub <url> --cast --lang ru --max-min 60`. Модель minimax ~в 4 раза дороже обычной; час многоголосья — несколько сотен рублей. Результат — mp3 (часовая озвучка не пролезает в 50 МБ).
- Озвучка всегда через очередь `iva-queue` (воркер один, задача занимает минуты).
- **Приватные ссылки не вскрываются и не обходятся** (принцип): либо владелец открывает доступ «Все, у кого есть ссылка» (роль «Читатель»), либо присылает файл в Telegram — вложения принимаются напрямую.
- Закрытое видео: смета может посчитаться, но на скачивании команда упадёт без списания денег.
