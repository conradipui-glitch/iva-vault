# Формат постов-мыслей для личного AI-блога

05.09.2026 владелец заказал 2–3 коротких поста-мысли для личного AI-блога и задал строгий формат: вернуть только JSON; первое предложение — суть в одно предложение, затем почему это интересно простыми словами; без эмодзи, без длинных тире (использовать двоеточие), без кликбейта и без личного опыта. Примерные темы дня — ИИ-режим Google показывает товары на 21,6% дороже, открытый ассистент с самообучением (autoharness), формализация Великой теоремы Ферма в строгий язык. Формат требует учитывать при написании подобных постов для площадки/блога владельца, независимо от дефолтов скилла повествования.
