# Провенанс постов — модель, специалисты, стоимость (iva-post-provenance)

По просьбе владельца (13.08.2026, msg 14:34): «чтобы в таблицу с постами добавлялась информация о том, какая модель использована конкретно и какие специалисты были задействованы для написания поста; минимум хотя бы по постам».

Создан скрипт `scripts/iva-post-provenance.py`: после каждой публикации (ручной и авто) дописывает запись в `data/posts.jsonl` с полями `ts`, `platform`, `url`, `model`, `perspectives` (список перспектив-специалистов через запятую), `writer` (iva|pool|специалист), `cost`, `note`. Записаны 4 поста от 12.08.

Решение владельца по выбору специалистов (msg 14:45): выбирать НЕ каждый раз, а в момент формирования списка постов — рядом с каждым постом одной строкой указывать рекомендуемого специалиста и скилл; отдельной итерации «а кого возьмём?» не делать (каждый запрос ~50k токенов). Посты без специалиста фиксировать как `perspectives: none` — чтобы сравнивать «со специалистом vs без» (это и есть тестирование). У владельца гипотеза о «мосте» (файл-прокладка с короткими правилами → CORE + роутер) — обсуждена, роутер предложено сделать отдельно.
