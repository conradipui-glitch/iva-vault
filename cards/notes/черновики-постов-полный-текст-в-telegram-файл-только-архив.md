# Черновики постов: полный текст в Telegram, файл только архив

## Правило: черновики присылать полным текстом (10.08.2026)

Владелец (Антон) объяснил: он общается с Ивой в основном через Telegram и не может открывать пути к файлам на сервере (data/news/captions/...). Присылать «черновик готов, лежит по адресу X» — бесполезно.

**Аксиома:** черновик поста для канала присылается в Telegram ПОЛНЫМ ТЕКСТОМ — как его увидит подписчик. Файл на сервере — только архивная копия, не предмет показа.

- Не давать служебные пути к файлам в чате.
- Не подменять текст черновика саммари/перечислением ключевых пунктов.
- Если нужен выбор из нескольких тем — показывать каждую полным текстом.

## Формат поста (голос Бориса, из конвейера)
Заголовок, лид, 1–2 абзаца, практический вывод. Без ссылок в финале (или с источником в конце, как договоримся). В черновике нет служебных пометок. Один сюжет — один пост.
