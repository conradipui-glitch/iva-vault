# Личная система памяти владельца RIG OpenMemory LightRag

Владелец собрал свою систему памяти для ИИ-агента на ноутбуке ~5 месяцев назад (до мейнстрима): RIG + обвязка OpenMemory и LightRag. Работает до сих пор.

Экономия токенов: в 4–6 раз больше полезной работы в сессиях кодинга (5-часовые лимиты). На его фоне TencentDB Agent Memory (Trendshift, август 2026) концептуально ничего нового не даёт; новизна — «производственность»: плагин в OpenClaw/Hermes, символьная краткосрочная память (Mermaid, экономия до 61% токенов), белый ящик, бенчмарки SWE-bench +9.93%, PersonaMem 48→76.

Вывод: когда в новостях про память агентов — сравнивать с его setup, у него есть практический опыт, это материал для авторского комментария.
