# raw/ — инбокс сырых материалов

Сюда попадает ВСЁ, что владелец хочет сохранить в базу знаний:
- статьи, ссылки, конспекты, транскрипты, заметки, идеи
- файлы, которые прислал в чат (скриншоты текста, документы)

Правила:
- Это СЫРЬЁ. Не редактировать вручную, только добавлять новые файлы.
- После появления файла — команда владельца «обработай raw» (или автоматически при следующем ходе):
  1. Прочитать материал.
  2. Создать/обновить карточки в vault/cards/ (write_card) и wiki-заметки.
  3. Обновить vault/MOC.md (оглавление).
  4. Отметить противоречия, если источники конфликтуют.
  5. Показать владельцу: что создано, какие связи найдены, что изменилось.
- Файлы из raw/ НЕ удаляются (история источника сохраняется).
