Изучила и сверила с официальной документацией Microsoft.

Это гайд по подключению MarkItDown MCP к Claude Desktop. Инструмент преобразует PDF, Word, Excel, PowerPoint и другие форматы в Markdown, сохраняя заголовки, таблицы, списки и ссылки.

Главные выводы:

• Сам инструмент реальный и полезный.  
• Заявление «экономия токенов до 70%» официально Microsoft не гарантирует — это маркетинговая оценка, результат зависит от документа.  
• «Поддерживает все типы файлов» — преувеличение: форматов много, но часть требует дополнительных модулей или платных облачных сервисов.  
• Сканированные PDF базовая установка нормально не решает: для OCR нужен отдельный плагин и, возможно, API модели.  
• Большие документы всё равно могут не поместиться в лимит MCP — найден реальный пример с результатом 51 тыс. токенов при лимите клиента 25 тыс.  
• В гайде пропущен важный риск: MCP работает с правами пользователя, принимает локальные и сетевые URI и не имеет встроенной авторизации. Microsoft рекомендует контейнер, localhost и минимальные права.

Для Ивы прямое подключение этого MCP сейчас не нужно. У нас уже есть локальная обработка:

• PDF — через pdftotext;  
• DOCX — через pandoc;  
• XLSX — через openpyxl;  
• с проверкой файлов, ограничением объёма и недоверенным режимом содержимого.

Если улучшать нашу обработку документов, безопаснее встроить MarkItDown как локальную библиотеку/CLI, а не как MCP: только проверенные локальные файлы, закреплённая версия, лимиты результата, разбиение больших документов и текущие конвертеры как резерв.

Итог: идея хорошая, но гайд сильно упрощён. Для новичка с Claude Desktop сойдёт; для Ивы внедрять «как написано» не стоит.
