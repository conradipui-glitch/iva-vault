1. ИИ-агенты научились верстать слайды

🚀 Кодинг-ассистенты больше не ограничиваются текстом в чате.. теперь они создают готовые файлы презентаций.

Появляется экосистема agent skills.. пакетов инструкций и скриптов, которые дают ИИ-агентам специализированные умения. Примером служит навык SlideSpeak для Claude Code, OpenClaw, Cursor, Codex и других совместимых агентов. Он генерирует настоящий редактируемый файл .pptx из структурированных данных. Установка.. командой `npx skills add SlideSpeak/skills`.

Раньше нейросети выдавали только текст, а всю рутину по оформлению слайдов приходилось делать руками. Теперь агент получает инструкцию-навык и может отдать результат в рабочем формате.

Вокруг появляются и другие узкие модули.. например, для специализированной графики. Но конкретные свойства таких инструментов нужно проверять отдельно: название навыка ещё не доказывает, что он работает именно так, как обещано.

Главный тренд.. нейросети превращаются из собеседников в исполнителей, способных отдавать готовые документы.

Какую рутинную задачу вы мечтаете передать ИИ-агенту в первую очередь?

2. Google выпустила Gemini 3.5 Transcribe

🎙 Превратить сумбурную голосовую запись в чистый документ без слов-паразитов теперь можно автоматически.

Google 26 августа представила Gemini 3.5 Transcribe.. модель превращает сырое аудио в отформатированный текст, обрабатывает самоисправления говорящего и убирает слова-паразиты.

Модель поддерживает собственный словарь, автоматически определяет более 85 языков и размечает до трёх говорящих с таймкодами. Поддержка большего числа спикеров пока экспериментальная.

Для разработчиков доступны потоковый Live API с задержкой менее секунды и Interactions API для готовых записей. В Google AI Studio и Enterprise Agent Platform модель доступна в public preview.

Google также приводит показатели WER.. 4,0% для потокового режима и 2,6% для обычных записей. Это данные самой компании со ссылкой на Artificial Analysis, а не независимая проверка.

Расшифровка постепенно превращается из необработанной стенограммы в готовый рабочий документ.

4. Google представила Gemini Omni 1.1 Flash

🎬 Генерация видео постепенно становится управляемым рабочим процессом, а не случайным экспериментом.

27 августа Google объявила о production-ready обновлении Gemini Omni 1.1 Flash для разработчиков.

Модель умеет анализировать до 10 секунд предыдущего контекста и продолжать сцену шагами по 10 секунд.. вплоть до 40 секунд общей длины. Можно задать первый и последний кадр, а также использовать видеореференс продолжительностью до 3 секунд.

Одна из проблем генерации видео.. высокая стоимость множества пробных вариантов и нестабильность при продолжении сцены. По заявлению Google, черновики в 360p создаются до 60% быстрее и стоят в треть цены версии 720p. Это показатели самой компании, а не независимый тест.

Финальный результат можно увеличить до 1080p или 4K. Модель доступна через Google AI Studio и Gemini Enterprise Agent Platform.

Чем вы бы воспользовались в первую очередь.. продолжением сцены или точным заданием первого и последнего кадра?

5. AI File Sorter: порядок на компьютере с помощью ИИ

📁 Папка «Загрузки» больше не обязана превращаться в склад файлов с названиями вроде `IMG_4821` и `final_final_2`.

На GitHub развивается AI File Sorter.. кроссплатформенный сортировщик файлов с открытым исходным кодом.

Изображения и документы приложение анализирует по содержимому. Для аудио и видео используются поддерживаемые метаданные, чтобы предложить понятные имена и категории.

Программа не должна менять файлы вслепую.. есть предварительный просмотр, подтверждение действий и функция Undo last run для отмены последнего запуска. Работать полностью локально можно при использовании локальной модели.. тогда данные не нужно отправлять в облачный сервис.

На момент проверки у проекта было около 1,6 тысячи звёзд, 165 форков и 927 коммитов на GitHub.

Это не «волшебная уборка одним кликом», а инструмент, которому всё равно стоит сначала дать тестовую папку и проверить предложения.

Доверили бы локальной нейросети разбор папки с загрузками?

Первоисточник: https://github.com/hyperfield/ai-file-sorter
