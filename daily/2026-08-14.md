Понял. Отвечаю на вопрос — кто интерпретирует астропрогноз:

**Никакой ИИ-модели там нет.** Утренний астропрогноз (07:00 по Омску) делает **чистый скрипт** `scripts/daily-astro.ts`, без участия нейросети:

1. **Движок** — локальный Python `repos/astrology-engine/astrology_engine.py` считает транзиты на сегодня, луну, руну дня, аспекты (транзит к натальной карте)
2. **Интерпретация** — захардкожена в скрипте: он берёт, в каком доме Юпитер/Венера/Марс/Луна и подставляет **готовую фразу из шаблона** (H2 → «фокус на деньгах», H8 → «осторожно с чужими деньгами», H7 → «партнёрства», и т.д.)
3. **Отправка** — шлёт в твой личный чат через Telegram API

То есть прогноз каждый день собирается из одного и того же шаблона + реальные данные движка (фаза луны, знак, руна, аспекты). Ни одна LLM не участвует — ни я, ни другая модель не интерпретируем.

**Нюанс:** шаблон бедноват — всего ~10 готовых фраз на дом. Если хочешь, могу сделать прогноз умнее: пусть скрипт собирает данные движка и отдаёт **мне** (или модели) для интерпретации — будет живее и точнее, но это будет уже не «бесплатный скрипт», а вызов модели (цена ~1-2 руб./день, и нужен ключ). Или оставить как есть — стабильно и бесплатно.
