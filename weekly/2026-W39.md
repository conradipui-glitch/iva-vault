# Week 39, 2026

## Themes

- **Threads: публикация возобновилась, вовлечение нулевое** — после паузы с 10.09 посты
  пошли с 20.09 (2 поста, 88 просмотров, ER ~3,4% за счёт ответов), но к 25–26.09 ER упал
  до 0–0.4%: читают, не задевает. Вывод 25.09 — вопросы/полемика в хвосте поста.
- **Стратегия «8 шагов»: из плана в механику** — 25.09 схема из PDF зафиксирована как план,
  26.09 внедрены все 5 пунктов и проверены: CTA-редиректы /go/ (коды th1/th2/th3), шаблон
  длинной ветки, недельная сетка с отсевом рубрик через 26.10, детектор хитов (порог 3×
  медианы = 570 просмотров, найдено 18 хитов), CTA-вставка в автоконвейер. Важная поправка:
  хиты считаются по просмотрам, не по лайкам (медиана лайков = 1 делает порог бессмысленным).
  Первый осмысленный замер кликов — через 1–2 недели.
- **X окончательно закрыт** — 25.09 диагноз: @TrampampamAGI suspended (403, профиль 404),
  разблокировка только через апелляцию владельца. X-ветка конвейера отключена (без неё
  +90 минут работы), владелец подтвердил: X давно на паузе, только чтение новостей.
- **Деградация пулов и поиск памяти** — iva-write не отвечает с 21.09 (четыре дня подряд;
  Antigravity отрезан гео-блоком по датацентровым IP, RouterAI в минусе −0,45 ₽) — все
  тексты недели написаны самой Ивой. Тот же минус на RouterAI сломал ночной сбор векторного
  индекса: поиск по памяти деградировал; варианты — пополнить RouterAI или ollama +
  nomic-embed-text, решение не принято. Гео-блок Antigravity разобран до механики: платный
  резидентский IP даёт шансы без гарантий — рекомендация RouterAI не принята.
- **Черновики копятся** — за неделю подготовлены: 3 поста и 10 заголовков для блога (21.09),
  3 черновика с обложками (Meta Muse, Suncatcher ×2; 25.09), 3 текста Threads (Пентагон/
  Anthropic, рой агентов, нейрочип; 26.09), 6 постов в двух партиях (VoiceStudio, Flock,
  софт для ИИ, джейлбрейки, Drawgent, brag; 27.09) — всё ждёт ОК. По правилу от 23.09
  черновики сохраняются в файл при каждом сигнале.
- **Прочее** — здоровье vault починено до 100.0 (битых ссылок 0); разбор paragon-JEV:
  недоделан и мёртв без ключа, пользы нет, предложен свой скилл чек-листа ТЗ; парк «Вокруг
  света» — всю неделю будничная тишина, единственное событие (квартирник 26.09 «провожаем
  сентябрь») прошло вне окна рассылки.
