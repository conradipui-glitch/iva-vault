# Новости — проект IVA

## Цель
Готовить свежие черновики для Telegram-канала об ИИ и технологиях.

## Режим на старте
- Только ручной запуск по явному запросу владельца.
- Результат — черновик; никакой публикации без отдельного подтверждения.
- n8n не используется и не изменяется этим проектом.

## Приоритет источников
1. Подключенные социальные источники и Reddit.
2. Официальные сайты, блоги разработчиков и первоисточники.
3. Hacker News — как сигнал, с проверкой первоисточника.
4. arXiv — редко и только для действительно новых релевантных работ.

## Правила качества
- Не использовать новость старше 72 часов, если пользователь прямо не просит ретроспективу.
- Не повторять уже использованный сюжет, URL или существенно тот же факт.
- Не писать, из каких внутренних источников собран материал, если это не требуется пользователю.
- Ссылки на первоисточник включать в черновик отдельной строкой для проверки.
